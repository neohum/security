대상 서버와 직접 통신하지 않고 공개 Whois 데이터베이스를 조회하므로 침입탐지시스템(IDS)에 어떤 로그도 남지 않습니다. 담당자 이메일과 서브넷 블록(172.28.0.0/16)을 파악하는 안전한 1차 정찰 기법입니다.

참고 커맨드 #1
영역 전송 DNS Zone Transfer (AXFR) 취약점 
dig axfr @172.28.0.15 megacorp.internal

보조 DNS 서버 동기화 프로토콜(AXFR)의 미흡한 접근 제어를 악용합니다. BIND의 allow-transfer가 개방되어 있으면 조직 내 모든 서브도메인(db, s3, backup 등) 전체가 단 한 번의 질의로 유출됩니다.

참고 커맨드 #2
스텔스 스캔 Nmap TCP SYN Half-Open 스캔 
nmap -sS -Pn 172.28.0.20

3-Way Handshake를 완결하지 않고 SYN/ACK 수신 즉시 RST를 보내 연결을 강제 종료합니다. 대상 서버의 애플리케이션 접속 로그에 남지 않고 포트 개방 여부만 파악할 수 있는 고전적 스텔스 기법입니다.

참고 커맨드 #3
MSF 보조 Metasploit Auxiliary 버전 지문 분석 
msfconsole -q -x "use auxiliary/scanner/smb/smb_version; set RHOSTS 172.28.0.20; run; exit"

공격 페이로드 투입 없이 원격 서비스 버전(SMB, MSSQL 등) 지문을 정밀 분석하고, 결과를 MSF 내장 DB(hosts, services)에 자동 체계화하여 후속 침투 벡터를 정밀 설계합니다.

참고 커맨드 #1
DNS 봉쇄 DNS Zone Transfer (AXFR) 차단 정책 
named.conf -> allow-transfer { none; };

신뢰할 수 있는 보조 DNS 서버 IP만 명시적으로 허용하고, 외부 일반 사용자의 모든 AXFR 질의는 거부(REFUSED)해야 내부 인프라 네트워크 매핑 공격을 원천 무력화할 수 있습니다.

참고 커맨드 #2
SYN 차단 패킷 레벨 SYN 스캔 임계치 제어 
iptables -A INPUT -p tcp --syn -m limit --limit 5/m -j ACCEPT

단시간 내 다수 포트로 쏟아지는 비정상 SYN 패킷 레이트를 감지하고 임계치 초과 시 방화벽 레벨에서 발원지 IP를 자동 DROP 처리하여 포트 스캔 및 서비스 거부 공격을 차단합니다.

참고 커맨드 #3
권한 잠금 S3 공개 버킷 폐쇄 및 SA 계정 보호 
mc anonymous set none myminio/megacorp-backup

클라우드 오브젝트 스토리지의 익명 다운로드 권한을 회수하고, 데이터베이스 기본 sa 관리자 계정을 비활성화하며 16자리 이상의 강력한 비밀번호를 강제하여 기본 설정 미흡(Misconfiguration)을 제거합니다.

🎯 Intent (목표)

『메타스플로잇 Metasploit, 2/e - 침투 테스트 실전 가이드』 3장 "인텔리전스 수집"의 전 과정(수동 정보 수집: 후이즈·넷크래프트·DNS 분석, 능동 정보 수집: Nmap·MSF 포트 스캔, 타깃 스캔: SMB·MSSQL·S3·SSH·FTP·SNMP, 커스텀 MSF 스캐너 제작)을 외부 인터넷 질의 없이 안전한 로컬 샌드박스에서 체험할 수 있는 인터랙티브 시뮬레이션 게임을 구축합니다. 특히 **호스트 PC로 Windows 10/11(Docker Desktop WSL2)** 1대를 중앙 서버로 지정하고, 동일 Wi-Fi 네트워크에 연결된 여러 대의 컴퓨터(Mac, Linux, Windows 노트북)가 별도 설치 없이 웹 브라우저(`http://{호스트IP}:3000`) 또는 SSH로 접속하여 **공격자(Attacker)**, **방어자(Defender)**, **관제/참관(Observer)** 역할을 실시간으로 분담 수행하는 LAN 협업 훈련 환경을 완성합니다. 윈도우 방화벽 인바운드 자동 등록, Wi-Fi IP 자동 감지, 역할별 전용 뷰 분기 및 실시간 패킷 동기화를 단일 원클릭 런처(`run-host.ps1`)로 제공합니다.

🚫 Non-goals (범위 외)

  • 실제 공용 인터넷(외부 Whois 레지스트리, 실제 Netcraft 도메인, 외부 AWS S3 등)으로의 실제 패킷 전송 (100% 로컬 샌드박스 격리)
  • 도서 3장 범위 외의 침투 익스플로잇(4장 이후의 취약점 공격 및 페이로드 셸 획득)으로의 과도한 범위 확장
  • 상용 SIEM/유료 침입탐지 소프트웨어 의존성 추가 (오픈소스 경량 도구로 자립 완결)
  • 참가자 컴퓨터(클라이언트)마다 Docker Desktop을 강제 설치시키는 분산 배포 방식 배제 (호스트 1대 집중형 Zero-Setup 채택)
